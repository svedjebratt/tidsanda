# Time Tracking

Tidsanda records periods of work and presents them in ways that make recurring work easy to continue.

## Language

**Time entry**:
A single continuously measured period of work with a start, a stop, and a set of tags.
_Avoid_: Session, tag group

**Tag group**:
A presentation of time entries whose tags form exactly the same set, regardless of tag order. A tag group is not itself a measured period of work.
_Avoid_: Time entry, merged entry

**Tag-group total**:
The sum of the durations of the displayed time entries in a tag group. An entry that spans midnight belongs entirely to the day on which it starts.
